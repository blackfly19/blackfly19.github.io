About

I'm a software engineer who mostly works on the backend: APIs, data platforms, and the cloud infrastructure that keeps services running. I spent two years at Bank of America, and before that I worked on Fission, an open-source serverless framework for Kubernetes.

Outside of work, I like picking a tool I use every day and building a small version of it myself. It's the best way I've found to understand how something really works, and it's how most of the projects below started.

Stile makes science lessons for schools, and teachers were spending hours writing test questions for them by hand. In a team of five, I built the Python and Flask backend for a tool that reads lesson content and generates curriculum-aligned questions automatically.

InfraCloud2021 – 2022
Software Engineer Intern · Fission

InfraCloud maintains Fission, a framework for running serverless functions on Kubernetes, and I worked on it full time. I rebuilt its monitoring so every core service reports request counts and response times to Prometheus, made its message-queue triggers react to changes instantly instead of checking every five seconds, and added a new fission archive command for managing stored code packages.

I also fixed a bug where requests could be sent to function pods that had already died, and locked down pod permissions so users no longer got root access by default. By the end I had over 70 pull requests merged, wrote the release notes for Fission 1.16, and published two tutorials on the Fission blog: autoscaling with custom metrics and Kafka on Confluent Cloud.

VinylIn progress

A version control system I'm building from scratch to understand how Git works under the hood. Files are stored by the hash of their contents, so identical files are only ever saved once, and each commit is a Merkle tree whose single root hash fingerprints the whole project. I left out Git's staging area to keep it simple: vin commit just saves whatever is in the folder.
